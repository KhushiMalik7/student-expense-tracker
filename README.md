## Pennywise

A responsive student expense tracker built with plain HTML, CSS, and JavaScript. Add income and expenses, set a monthly budget, and see a simple spending breakdown. Your data is saved in this browser using `localStorage`.

## Run it

Open `index.html` in a modern browser. No installation or build step is needed. The interface uses Google Fonts when an internet connection is available and falls back to local sans-serif fonts otherwise.

## Data

Transactions and the monthly budget stay in the browser where they were entered. They are not sent to a server. Clearing the browser's site data will clear them.
